🧩 运行时覆盖层 (Runtime Overlays)

当启动特定功能时叠加在主面板上的独立 UI 层，通过 SetTradeDetailsVisible(false) 隐藏主面板细节。

1. PartnerPickerOverlay — 选择交易对象

交易对象不明时弹出。复用 MessageDialog prefab，运行时构建 ScrollRect 列表。
列表过滤：同 Stage + 同坐标 + IsShopLikeLocation()（匹配 Shop/Trade/Gap 等）。
支持本地调试虚拟玩家 AI Default / AI Default 2。
构建失败时回退到 ShowTradeTargetUnavailableDialog 错误弹窗。
EnsurePartnerPickerOverlay() RebuildPartnerPickerList() OnPartnerSelected()

🎯 可点击玩家列表（通过 CreateTextButton 构建，悬停放大 1.08，按下放大 1.12）
🧑 玩家A Shop - Act 1, (3,5) - 同节点
🧑 玩家B Shop - Act 1, (3,5) - 同节点 [Host]
🤖 AI Default Trade - Act 1, (3,5) - 同节点 (本地调试)
2. CardPickerOverlay

从自身卡组选择要交易的卡牌。复用 ShowCardsPanel 构建，支持多种排序（实际/索引/类型/稀有度）和过滤（追放/梦境）。
EnsureCardPickerOverlay() ShowCardPickerOverlay()

3. ExhibitPickerOverlay

选择要交易的展品。通过 RuntimeSelectionPanelFactory 创建模态对话框，展示所有可交易展品列表。
EnsureExhibitPickerOverlay() ShowExhibitPickerOverlay()

4. OfferPreviewOverlay

双方报价卡牌缩略预览。本地侧与远端侧并排展示，自动缩放适应布局。
EnsureOfferPreviewOverlay() RefreshOfferPreview()

🃏 卡牌交易操作

  • AddCardToTrade(card, isPlayer1) — 将卡放入指定侧槽位，更新预览
  • RemoveCardFromTrade(card, isPlayer1) — 移除已放入卡牌，重排后序槽位
  • 槽位上限 _maxTradeSlots（默认 5），联机模式远端侧锁定
