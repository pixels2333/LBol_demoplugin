🧩 运行时行为细节

🎯 选择即治疗
点击玩家行即自动选择并触发治疗，无需二次确认。
选中行会高亮边框。
在发送请求后，所有按钮禁用等待结果。
🔗 网络同步流程
点击治疗 → SendGameEventData(OnGapHealRequest)
Host 验证 → 广播 ResurrectResult
成功 → 治疗落地 → DidCompleteTreatment = true
失败 → 提示原因，重新激活按钮
CreatePlayerRow() OnResurrectPlayer() OnResurrectResult() RowHoverScale

🎯 治疗流程

  • 点击行 → _selectedPlayer 赋值 → 自动触发 OnResurrectPlayer
  • 生成 _pendingRequestId → 发送网络请求
  • 禁用所有按钮 → 等待 Host 回包
  • 本地调试模式（AI Default）跳过网络，立即成功

🔄 网络同步

  • ResurrectSyncPatch 驱动治疗结果分发
  • OnResurrectResult 回调处理成功/失败
  • 成功：ApplyTreatment() 执行治疗
  • 失败：显示原因，允许重试
