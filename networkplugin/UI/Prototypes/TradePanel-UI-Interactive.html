🧩 运行时覆盖层 (Runtime Overlays)

当启动特定功能时叠加在主面板上的独立 UI 层，通过 SetTradeDetailsVisible(false) 隐藏主面板细节。

1. PartnerPickerOverlay

见上方独立卡片 👆 可交互玩家列表。
EnsurePartnerPickerOverlay() RebuildPartnerPickerList()

2. CardPickerOverlay

从自身卡组选择要交易的卡牌。复用 ShowCardsPanel 构建，支持多种排序（实际/索引/类型/稀有度）和过滤（追放/梦境）。
EnsureCardPickerOverlay() ShowCardPickerOverlay()

3. ExhibitPickerOverlay

见上方独立卡片 👆 可交互展品列表。
EnsureExhibitPickerOverlay() ShowExhibitPickerOverlay()

4. OfferPreviewOverlay

双方报价卡牌缩略预览。本地侧与远端侧并排展示，自动缩放适应布局。
EnsureOfferPreviewOverlay() RefreshOfferPreview()

🃏 卡牌交易操作

  • AddCardToTrade(card, isPlayer1) — 将卡放入指定侧槽位，更新预览
  • RemoveCardFromTrade(card, isPlayer1) — 移除已放入卡牌，重排后序槽位
  • 槽位上限 _maxTradeSlots（默认 5），联机模式远端侧锁定

→
