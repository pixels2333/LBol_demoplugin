# 会话交接与上下文压缩 (Handoff)

本技能用于将当前会话的上下文、进展、已完成产物、待办事项和决策沉淀为结构化的交接文档（Handoff Document），以便后续会话或接力 Agent 无缝接手。

## 核心原则

1. **中文撰写**：交接文档及说明必须使用清晰、结构化的中文撰写。
2. **精炼引用，避免冗余**：对于已存在于项目中的规范、实施计划、架构文档、提交记录或代码，使用文件链接（如 `[path](file:///...)`）或相对路径引用，不盲目全文复制。
3. **严密脱敏**：彻底脱敏所有敏感信息（如 API Key、Token、密码、个人私密信息等）。
4. **聚焦目标**：如果用户提供了后续任务描述或参数（例如后续会话的重点方向），交接文档应紧扣该方向进行针对性梳理。

## 交接文档标准模板

生成的交接文档建议保存为 Artifact 或输出到系统临时目录/用户指定位置，结构如下：

```markdown
# 工作交接文档 (Handoff)

## 1. 任务背景与核心目标
- **原始任务**：简要说明初始需求。
- **当前重点**：说明当前正在处理的核心问题。

## 2. 当前进展与产物
- **已完成工作**：列出已实现的功能、已修复的问题。
- **关键文件与产物**：
  - [修改文件或文档链接] - 说明变更内容
- **当前状态**：描述目前系统/代码库的运行与测试状态。

## 3. 未决事项与阻塞点 (Blockers)
- 待解决的遗留问题或已知 Bug。
- 需要用户决策或外部依赖的事项。

## 4. 关键技术决策 (Decisions & Trade-offs)
- 已做出的关键技术选型或架构折衷。
- 需注意的隐性约束或设计约定。

## 5. 下一步行动建议与推荐 Skills
- **接力 Agent 优先执行动作**：明确 1、2、3 步具体操作。
- **建议调用的 Skills / Tools**：列出接力 Agent 在后续步骤中应当触发的 Skill 名称及原因。
```

## 执行流程

1. 梳理当前会话的全流程上下文。
2. 提取核心进展、关键产物链接与遗留事项。
3. 按上述标准模板生成中文交接文档。
4. 提示用户交接文档已生成，并给出在新会话中快速唤醒接力的建议提示词。
