# 重新梳理与通俗化解释 (Wait-What)

当用户触发此技能时，说明上一条消息或当前方案未能清晰传达。**必须暂停技术细节展开**，退回高层视角，用简明通俗的中文重新梳理与解释。

## 核心执行原则

1. **统一中文交流**：全程使用自然、通俗易懂的简体中文输出。
2. **拒绝行话堆砌**：避免生僻缩写或跳跃式逻辑，多用类比和清晰结构。
3. **结合项目上下文**：若项目中存在 `CONTEXT.md` 或相关说明文档，请使用其中约定的领域通用词汇（Ubiquitous Language）。
4. **定位与分步清晰**：帮助用户快速重新定位“我们在哪、在做什么、下一步是什么”。

## 响应结构与步骤

请按以下三段式结构向用户重新汇报：

### 1. 现状与上下文对齐 (Where We Are)
- 一句话说明我们当前正在解决什么核心问题或处于哪一阶段。
- 简短说明为何需要做这件事（背后的业务或技术意图）。

### 2. 白话重新解释 (The Core Idea)
- 用平实直白的语言重新阐述上一条消息的核心观点、方案或修改。
- 如果涉及复杂机制，使用简单直观的比喻或图示（如时序/流程流程）辅助说明。

### 3. 下一步与选择项 (What's Next)
- 明确给出接下来的 1~3 个具体可执行动作或待确认选项。
- 询问用户是否理解，或是否有需要调整的方向。
